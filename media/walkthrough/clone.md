# Clone a GitLab group or GitHub organization

Run **CANOPY: Clone from GitLab Group…** or **CANOPY: Clone from GitHub Organization…**:

1. Pick a group (or type its path), or a GitHub organization or your own account.
2. Tick the projects you want. Projects you already have are left unticked.
3. Choose a folder to clone into.

CANOPY shows the plan, clones each project on its default branch, and files them into CANOPY folders: GitLab subgroups become nested folders, and a GitHub organization becomes one folder.

**Profile from GitLab Group…** and **Profile from GitHub Organization…** do the same but open the result as a profile. You can then adjust branches and share it before anything is cloned.
